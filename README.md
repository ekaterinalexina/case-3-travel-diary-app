# Дневник путешествий

Веб-приложение для ведения дневника путешествий, созданное на Flask + SQLite с интерактивными картами Leaflet.js.

## Возможности

- **Регистрация и авторизация** — создание аккаунта, вход и выход из системы (Flask-Login)
- **Записи о путешествиях** — создание, редактирование и удаление записей с названием, описанием, страной, городом, датами
- **Публичная лента** — просмотр путешествий других пользователей с фильтрами по стране и сортировкой
- **Геопозиция на карте** — указание широты и долготы, отображение местоположения на интерактивной карте OpenStreetMap (Leaflet.js)
- **Стоимость путешествия** — указание общей стоимости и валюты
- **Оценки** — рейтинг по трём критериям: удобство, безопасность и природа (1-5 звёзд)
- **Профили пользователей** — просмотр профиля и публичных путешествий любого пользователя

## Технологии

- Python 3 / Flask
- SQLite (через встроенный модуль sqlite3)
- Flask-Login (авторизация)
- Werkzeug (хеширование паролей)
- Leaflet.js + OpenStreetMap (интерактивные карты)
- HTML5 / CSS3 (адаптивная вёрстка)

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd Кейс_3
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   venv\Scripts\activate       # Windows
   # source venv/bin/activate  # Linux/macOS
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python app.py
   ```

4. Откройте в браузере: [http://localhost:5000](http://localhost:5000)

## Демо-данные

При первом запуске база данных автоматически заполняется демонстрационными данными:

- **Демо-пользователь:** `demo` / `demo123`
- **Второй пользователь:** `traveler` / `travel123`
- **8 путешествий** с реальными координатами городов: Москва, Париж, Токио, Рим, Стамбул, Барселона, Санкт-Петербург, Бангкок

## Таблицы базы данных

### users
| Поле          | Тип       | Описание                    |
|---------------|-----------|------------------------------|
| id            | INTEGER   | Первичный ключ               |
| username      | TEXT      | Имя пользователя (уникально) |
| email         | TEXT      | Электронная почта (уникально) |
| password_hash | TEXT      | Хеш пароля                   |
| created_at    | TIMESTAMP | Дата регистрации             |

### trips
| Поле               | Тип     | Описание                      |
|--------------------|---------|--------------------------------|
| id                 | INTEGER | Первичный ключ                 |
| user_id            | INTEGER | Внешний ключ на users          |
| title              | TEXT    | Название путешествия           |
| description        | TEXT    | Описание                       |
| country            | TEXT    | Страна                         |
| city               | TEXT    | Город                          |
| latitude           | REAL    | Широта                         |
| longitude          | REAL    | Долгота                        |
| date_start         | DATE    | Дата начала                    |
| date_end           | DATE    | Дата окончания                 |
| total_cost         | REAL    | Общая стоимость                |
| currency           | TEXT    | Валюта (RUB, USD, EUR и др.)   |
| rating_convenience | INTEGER | Оценка удобства (1-5)          |
| rating_safety      | INTEGER | Оценка безопасности (1-5)      |
| rating_nature      | INTEGER | Оценка природы (1-5)           |
| visibility         | TEXT    | Видимость (public/private)     |
| created_at         | TIMESTAMP | Дата создания записи         |
